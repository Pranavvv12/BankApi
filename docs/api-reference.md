Registered in: `src/routes/accounts.routes.ts`

| --- | --- | --- | --- | --- |
| `customerId` | integer | Yes | ID of the customer | `1` |

## Transfers

### `POST` `/transfers`

Transfer money between accounts

Transfers a specified amount from one account to another. Supports idempotency to prevent duplicate transfers.

Registered in: `src/routes/transfers.routes.ts`

**Parameters**

| In | Name | Type | Required | Description | Example |
| --- | --- | --- | --- | --- | --- |
| header | `Idempotency-Key` | string | No | Optional idempotency key to prevent duplicate transfers (valid for 24h) | `transfer-123e4567-e89b-12d3-a456-426614174000` |

**Request body** (required)

| Field | Type | Required | Description | Example |
| --- | --- | --- | --- | --- |
| `amount` | number | Yes | Amount to transfer — min: 0.01 | `250.75` |
| `fromAccountId` | integer | Yes | Source account ID | `1` |
| `toAccountId` | integer | Yes | Destination account ID (must be different from source) | `2` |

Example request:

```json
{
  "fromAccountId": 1,
  "toAccountId": 2,
  "amount": 250.75
}
```

**Responses**

| Status | Description |
| --- | --- |
| `201` | Transfer completed successfully |
| `400` | Bad request (insufficient funds, validation error, same account transfer) |
| `404` | Account not found |

Example response `201`:

```json
{
  "id": 1,
  "fromAccount": 1,
  "toAccount": 2,
  "amount": "250.75"
}
```

Example response `400`:

```json
{
  "error": {
    "message": "Insufficient funds"
  }
}
```

Example response `404`:

```json
{
  "error": {
    "message": "Account not found"
  }
}
```
